# App 隐私

- Tracking: No
- Data linked to the user: None
- Data not linked to the user: None
- Data types collected: None
- Third-party advertising: None
- Third-party analytics: None
- Account creation: None
- Network access by the app: None
- Local progress: Stored only on device through WKWebView data storage
- User-initiated sharing: Uses system save/share UI only

The privacy manifest at `LittleColorist/Resources/PrivacyInfo.xcprivacy` declares no tracking, no collected data types, and no app-owned required-reason APIs.
